# forgebase_project (Resource)

A project: a group of environments (tenants). A new project gets `development`, `staging` and `production` environments. The server has no update call for projects, so every change replaces it. Environments cannot be added or removed individually through the provider (the API only creates them).

## Example Usage

```terraform
resource "forgebase_project" "web" {
  org  = forgebase_org.acme.id
  slug = "web"
  name = "Web"
}

# Each environment is a tenant: use its id in the provider's tenant argument.
output "production_tenant" {
  value = one([for e in forgebase_project.web.environments : e.id if e.name == "production"])
}
```
