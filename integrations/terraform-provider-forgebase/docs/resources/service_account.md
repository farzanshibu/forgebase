# forgebase_service_account (Resource)

A service account: a machine identity that owns API keys (`forgebase_api_key`). The server has no update call for service accounts, so every change replaces it.

## Example Usage

```terraform
resource "forgebase_service_account" "ci" {
  name        = "ci-deploys"
  description = "Used by the deploy pipeline"
}
```

### Optional

- `id` (String) Server-assigned id.
