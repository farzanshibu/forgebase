# forgebase_storage_bucket (Resource)

An object-storage bucket and its default policy. Per-principal access lives in `forgebase_storage_bucket_acl`.

## Example Usage

```terraform
resource "forgebase_storage_bucket" "avatars" {
  name                  = "avatars"
  visibility            = "public"
  versioning            = true
  max_object_bytes      = 5 * 1024 * 1024
  allowed_content_types = ["image/png", "image/jpeg", "image/webp"]
}
```

## Schema

### Required

- `name` (String) Bucket name: 1-63 characters of `a-z`, `0-9`, `.`, `_` and `-`, starting with a letter or digit. Cannot change.

### Optional

- `allowed_content_types` (Set of String) Content types uploads may use (for example `image/png`). Omit to allow any.
- `force_destroy` (Boolean) Delete the bucket's objects when destroying it. Without it the server refuses to delete a non-empty bucket.
- `max_object_bytes` (Number) Largest object accepted, in bytes. Omit for no limit.
- `versioning` (Boolean) Keep earlier versions of overwritten objects.
- `visibility` (String) Default read access: `private` (default), `authenticated` or `public`.

### Read-Only

- `created_at` (String) Creation time.
- `id` (String) The bucket name.
- `owner` (String) Principal that created the bucket.
- `tenant` (String) Tenant the bucket belongs to, if any.
- `updated_at` (String) Last change.
