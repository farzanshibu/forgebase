# forgebase_oauth_client (Resource)

An OAuth 2.0 / OpenID Connect client app of ForgeBase's identity provider. A confidential client's secret is returned by the server once, at creation, and is kept in `client_secret` (sensitive). Rotating the secret is not a Terraform operation; replace the resource (`terraform apply -replace=…`) or call `POST /api/auth/clients/{id}/secret` for a graceful rotation, then update consumers.

## Example Usage

```terraform
resource "forgebase_oauth_client" "web" {
  name          = "Web app"
  description   = "The customer web app"
  redirect_uris = ["https://app.example.com/auth/callback"]
  scopes        = ["openid", "profile", "email", "offline_access"]

  access_token_ttl = 900
}

resource "forgebase_oauth_client" "spa" {
  name          = "Single-page app"
  type          = "public" # no secret; PKCE required
  redirect_uris = ["https://spa.example.com/"]
}

output "web_client_secret" {
  value     = forgebase_oauth_client.web.client_secret
  sensitive = true
}
```

## Schema

### Required

- `name` (String) Display name shown on the consent screen.

### Optional

- `access_token_ttl` (Number) Access-token lifetime in seconds (60-86400). Removing a set value replaces the client (the server cannot clear an override).
- `description` (String) Description.
- `disabled` (Boolean) Refuse new authorizations and tokens.
- `grant_types` (Set of String) Allowed grants: `authorization_code`, `refresh_token`, `client_credentials`, `urn:ietf:params:oauth:grant-type:device_code`. Default `authorization_code` and `refresh_token`.
- `post_logout_redirect_uris` (Set of String) Allowed post-logout redirect URIs (exact match, at most 20).
- `realm` (String) Realm of the client. Defaults to the provider's realm, else `default`. Cannot change.
- `redirect_uris` (Set of String) Allowed redirect URIs (exact match, at most 20). Required for the `authorization_code` grant.
- `refresh_token_ttl` (Number) Refresh-token family lifetime in seconds (300-31536000). Removing a set value replaces the client (the server cannot clear an override).
- `scopes` (Set of String) Scopes the client may request: `openid`, `profile`, `email`, `phone`, `offline_access` or a ForgeBase API scope. Default `openid profile email offline_access`.
- `skip_consent` (Boolean) First-party app: no consent screen.
- `type` (String) `confidential` (keeps a secret; default) or `public` (browser or native app; PKCE required). Cannot change.

### Read-Only

- `client_secret` (String, Sensitive) Secret of a confidential client. Only known when Terraform created the client (null for public clients and imported ones).
- `created_at` (String) Creation time.
- `id` (String) The `client_id`.
- `updated_at` (String) Last change.


## Import

Import is supported using the following syntax:

```shell
# By client_id. The client secret cannot be recovered: client_secret stays null.
terraform import forgebase_oauth_client.web cli_abc123
```
