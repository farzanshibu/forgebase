# forgebase_feature (Resource)

An entitlement feature of the catalog: something a plan can include or limit (an API, a quota, a rate). Requires a platform-administrator credential.

## Example Usage

```terraform
resource "forgebase_feature" "ai_generation" {
  key         = "ai_generation"
  name        = "AI generation"
  kind        = "metered"
  unit        = "requests"
  permissions = ["ai:*"]
}
```

## Schema

### Required

- `key` (String) Feature key (for example `ai_generation`). Cannot change.
- `kind` (String) What the feature measures: `boolean`, `metered`, `gauge`, `concurrency` or `rate`.

### Optional

- `description` (String) Description.
- `name` (String) Display name (defaults to the key).
- `permissions` (Set of String) Permission patterns this feature gates.
- `unit` (String) Unit shown with limits (`requests`, `bytes`).

- `id` (String) The feature key.
- `updated_at` (String) Last change.
