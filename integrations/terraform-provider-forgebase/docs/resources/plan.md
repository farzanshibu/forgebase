# forgebase_plan (Resource)

An entitlement plan: a named bundle of features and limits that subscriptions grant. Requires a platform-administrator credential. The plan's `features` list is replaced as a whole.

## Example Usage

```terraform
resource "forgebase_plan" "pro" {
  key        = "pro"
  name       = "Pro"
  trial_days = 14

  features = [
    {
      feature = forgebase_feature.ai_generation.key
      limit   = 10000
      period  = "month"
    },
  ]
}
```

## Schema

### Required

- `key` (String) Plan key (for example `free`, `pro`). Cannot change.

### Optional

- `active` (Boolean) The plan can be assigned.
- `description` (String) Description.
- `features` (Attributes List) Features the plan includes, with their limits. (see [below for nested schema](#nestedatt--features))
- `is_default` (Boolean) Plan of subjects without an entitled subscription. Making a plan the default unsets the previous default.
- `metadata` (String) Free-form data as a JSON object.
- `name` (String) Display name (defaults to the key).
- `trial_days` (Number) Trial length offered with the plan.

### Read-Only

- `created_at` (String) Creation time.
- `id` (String) The plan key.
- `updated_at` (String) Last change.

### Nested Schema for `features`

### Required

- `feature` (String) Feature key (a `forgebase_feature`).

### Optional

- `enabled` (Boolean) Included.
- `limit` (Number) Limit per period. Omit for unlimited.
- `period` (String) Window of the limit: `none`, `hour`, `day`, `month`, `lifetime` or `rolling`. Default `month` for metered features, `none` otherwise.
- `trial_limit` (Number) Allowance while the subscription is trialing (replaces `limit`).
- `unit` (String) Unit shown with the limit (defaults to the feature's).
- `window_secs` (Number) Length of a `rolling` window in seconds.
