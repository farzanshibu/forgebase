# forgebase_queue_topic (Resource)

A durable queue / pub-sub topic. Messages are kept for `retention_ms`; each subscription has its own cursor.

## Example Usage

```terraform
resource "forgebase_queue_topic" "orders" {
  name         = "orders"
  retention_ms = 7 * 24 * 60 * 60 * 1000

  labels = {
    team = "billing"
  }

  schema = jsonencode({
    type     = "object"
    required = ["order_id"]
  })
}

# A topic fed by record changes of a collection.
resource "forgebase_queue_topic" "post_changes" {
  name = "post-changes"

  source = {
    collection = forgebase_collection.posts.name
    ops        = ["create", "update"]
  }
}
```

## Schema

### Required

- `name` (String) Topic name (letters, digits, `.`, `_`, `-`). Cannot change.

### Optional

- `dedup_window_ms` (Number) Window in which a repeated `dedup_id` is accepted once, in milliseconds (at least 1000). Server default when omitted.
- `force_destroy` (Boolean) Also delete the topic's subscriptions when destroying it. Without it the server refuses while subscriptions exist.
- `labels` (Map of String) Free-form labels.
- `max_message_bytes` (Number) Largest accepted message in bytes (at least 64). Server default when omitted.
- `retention_bytes` (Number) Size cap per topic in bytes (at least 1024). Omit for no cap.
- `retention_ms` (Number) How long messages are kept, in milliseconds (at least 60000). Server default when omitted.
- `schema` (String) JSON Schema (as a JSON document) every published message must satisfy. Not allowed with `source`.
- `source` (Attributes) Feed the topic from record changes of a collection. Requires an administrator; cannot change after creation. (see [below for nested schema](#nestedatt--source))

### Read-Only

- `created_at` (String) Creation time.
- `created_by` (String) Creator.
- `id` (String) The topic name.
- `updated_at` (String) Last change.

### Nested Schema for `source`
