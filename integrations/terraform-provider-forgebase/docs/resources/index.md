# forgebase_index (Resource)

A manual index on a collection (B-tree, unique, partial, expression, JSON path, or full-text). The server cannot alter an index, so every change replaces it. Indexes derived from field flags (`unique`) are managed by the collection.

## Example Usage

```terraform
resource "forgebase_index" "posts_status" {
  name       = "idx_posts_status_published"
  collection = forgebase_collection.posts.name

  keys = [
    { path = "status" },
    { path = "published_at", desc = true },
  ]
}

resource "forgebase_index" "posts_search" {
  collection = forgebase_collection.posts.name
  kind       = "fulltext"
  keys       = [{ path = "title" }]
}
```
