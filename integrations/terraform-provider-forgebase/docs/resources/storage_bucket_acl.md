# forgebase_storage_bucket_acl (Resource)

The complete access-control list of one bucket. The resource owns the whole list: entries added outside Terraform are removed on the next apply. Destroying it empties the list.

## Example Usage

```terraform
resource "forgebase_storage_bucket_acl" "avatars" {
  bucket = forgebase_storage_bucket.avatars.name

  entries = [
    { grantee = "authenticated", permission = "write", prefix = "uploads/" },
    { grantee = "role:moderators", permission = "admin" },
  ]
}
```
