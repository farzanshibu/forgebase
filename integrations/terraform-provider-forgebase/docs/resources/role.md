# forgebase_role (Resource)

A custom role: a named set of permission patterns. Without `org` it is a realm role (needs a super-admin credential); with `org` it is an organization role. Roles seeded by the server can be imported, but only super-admins may change them.

## Example Usage

```terraform
# A realm role (needs a super-admin credential).
resource "forgebase_role" "editor" {
  key         = "editor"
  name        = "Editor"
  description = "Edits content, cannot delete collections"

  allow = ["collections:read", "records:*"]
  deny  = ["collections:delete"]
}

# An organization role.
resource "forgebase_role" "billing" {
  key   = "billing"
  org   = forgebase_org.acme.id
  allow = ["billing:read"]
}
```

## Schema

### Required

- `key` (String) Role key: 1-64 of `a-z`, `0-9`, `-`, `_`. Cannot change.

### Optional

- `allow` (Set of String) Permission patterns granted (for example `collections:read`, `storage:*`).
- `deny` (Set of String) Permission patterns denied. A deny wins over an allow.
- `description` (String) Description.
- `name` (String) Display name (defaults to the key).
- `org` (String) Organization id for an organization role. Omit for a realm role.

### Read-Only

- `id` (String) `<key>` for a realm role, `<org>/<key>` for an organization role.
- `system` (Boolean) Seeded by the server.


## Import

Import is supported using the following syntax:

```shell
# A realm role by key, an organization role as <org_id>/<key>.
terraform import forgebase_role.editor editor
terraform import forgebase_role.billing org_abc123/billing
```
