# forgebase_queue_subscription (Resource)

A subscription to a topic: a pull subscription (consumers call the pull API) or a push subscription (the server delivers to a webhook URL or a function). A webhook subscription's signing secret is returned by the server once, when the webhook is set, and is kept in `push_secret` (sensitive).

## Example Usage

```terraform
resource "forgebase_queue_topic" "orders_dead" {
  name = "orders-dead"
}

# Pull subscription: consumers call the pull API.
resource "forgebase_queue_subscription" "worker" {
  name                  = "order-worker"
  topic                 = forgebase_queue_topic.orders.name
  ack_deadline_ms       = 30000
  max_delivery_attempts = 5
  dead_letter_topic     = forgebase_queue_topic.orders_dead.name
}

# Push subscription: the server calls a webhook. The signing secret is
# returned once by the server and kept (sensitive) in push_secret.
resource "forgebase_queue_subscription" "hook" {
  name  = "order-hook"
  topic = forgebase_queue_topic.orders.name

  push = {
    kind     = "webhook"
    endpoint = "https://example.com/hooks/orders"
  }
}

output "order_hook_secret" {
  value     = forgebase_queue_subscription.hook.push_secret
  sensitive = true
}
```

## Schema

### Required

- `name` (String) Subscription name. Cannot change.
- `topic` (String) Topic to subscribe to. Cannot change.

### Optional

- `ack_deadline_ms` (Number) Time a consumer has to acknowledge a delivery, in milliseconds (1000-600000; default 10000).
- `backoff_base_ms` (Number) First redelivery delay in milliseconds (0-600000; default 1000).
- `backoff_max_ms` (Number) Longest redelivery delay in milliseconds (at least `backoff_base_ms`, at most 3600000; default 600000).
- `dead_letter_topic` (String) Topic that receives messages after `max_delivery_attempts`. Must differ from `topic`.
- `filter` (String) Attribute filter as a JSON document. Cannot change.
- `labels` (Map of String) Free-form labels.
- `max_delivery_attempts` (Number) Attempts before a message goes to the dead-letter list or topic (1-100). Omit for unlimited.
- `ordering` (Boolean) Deliver messages that share an ordering key one at a time, in order. Cannot change.
- `push` (Attributes) Push delivery. Omit for a pull subscription. Changing the endpoint of a webhook rotates its secret. (see [below for nested schema](#nestedatt--push))
- `start` (String) Where a new subscription starts reading: `latest` (default), `earliest`, or an RFC 3339 time. Used at creation only.

### Read-Only

- `created_at` (String) Creation time.
- `created_by` (String) Creator.
- `id` (String) The subscription name.
- `push_secret` (String, Sensitive) Signing secret of a webhook subscription, returned by the server only when the webhook is created or changed. Stored in state; the server cannot show it again.
- `updated_at` (String) Last change.

### Nested Schema for `push`

### Required

- `endpoint` (String) Webhook URL (must be https:// and a public address) or function name.
- `kind` (String) `webhook` (HTTPS URL) or `function` (name of a ForgeBase function).


## Import

Import is supported using the following syntax:

```shell
# The webhook secret cannot be recovered on import: push_secret stays null.
terraform import forgebase_queue_subscription.worker order-worker
```
