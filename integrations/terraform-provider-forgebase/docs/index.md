# ForgeBase Provider

Manage ForgeBase configuration (collections, storage, queues, functions, identity and more) through its REST API.

The provider talks to the server's REST API (`/api/v1`, `/api/auth`) with one credential: a service-account API key (`fbk_…`), a personal access token (`fbp_…`) or an access token. Most resources need an administrator credential; each resource page notes what it requires.

## Example Usage

```terraform
terraform {
  required_providers {
    forgebase = {
      source = "forgebase/forgebase"
    }
  }
}

# url and token can also come from FORGEBASE_URL and FORGEBASE_TOKEN.
provider "forgebase" {
  url   = "https://forgebase.example.com"
  token = var.forgebase_token # a service-account API key (fbk_…) or a personal access token
}

variable "forgebase_token" {
  type      = string
  sensitive = true
}
```

## Authentication and tenancy

- `url` and `token` default to the `FORGEBASE_URL` and `FORGEBASE_TOKEN` environment variables, so no secret has to appear in configuration.
- `realm`, `org` and `tenant` set the `X-Forgebase-Realm`, `X-Forgebase-Org` and `X-Forgebase-Tenant` headers. Set `tenant` to an environment id (see `forgebase_project`) to manage that environment's collections, buckets and queues.
- Credentials that carry scopes (`<area>:read|write`) need `write` on every area the configuration touches, and `read` for refresh.

## Schema

### Optional

- `insecure_skip_verify` (Boolean) Skip TLS certificate verification. Only for development. Defaults to the `FORGEBASE_INSECURE` environment variable.
- `org` (String) Organization sent as the `X-Forgebase-Org` header. Defaults to the `FORGEBASE_ORG` environment variable.
- `realm` (String) Realm sent as the `X-Forgebase-Realm` header. Defaults to the `FORGEBASE_REALM` environment variable.
- `tenant` (String) Tenant (environment id) sent as the `X-Forgebase-Tenant` header, so resources are created inside that environment. Defaults to the `FORGEBASE_TENANT` environment variable.
- `token` (String, Sensitive) Credential sent as `Authorization: Bearer <token>`: a service-account API key (`fbk_…`), a personal access token (`fbp_…`) or an access token. Defaults to the `FORGEBASE_TOKEN` environment variable.
- `url` (String) Base URL of the ForgeBase server, e.g. `https://forgebase.example.com`. Defaults to the `FORGEBASE_URL` environment variable.
